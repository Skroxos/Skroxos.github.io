Overview

Drone Assembly Simulator is not just a local VR experience; it's a fully integrated full-stack application. While the player interacts with drone components in virtual reality, the project serves as a showcase of a complete production pipeline.

The goal was to move beyond simple Unity gameplay and implement a robust architecture that handles cloud data, automated testing, and Infrastructure as Code (IaC).

Architecture & Stack

  • VR Client (Unity/C#): Clean architecture utilizing custom Editor Tools to accelerate development and Unit Tests to ensure logic stability.
  • Backend Service (PHP): A custom REST API acting as a bridge between the VR client and the database.
  • Cloud Database (Azure SQL): Secure and scalable data storage hosted on Microsoft Azure.
  • DevOps (Terraform): Entire server infrastructure is defined and deployed through code (Infrastructure as Code) using Terraform.
  • CI/CD Pipeline: Automated workflows that run Unit Tests and handle builds to prevent broken code from reaching production.

Challenges & Learning

The most significant technical hurdle was the context switch from pure game development to DevOps and cloud infrastructure. Configuring Terraform for an automated Azure deployment and ensuring the CI pipeline reliably executed Unity Unit Tests required deep research outside the standard game developer skill set.

This project fundamentally changed how I view software architecture. I learned that a solid CI/CD pipeline and automated testing are not just "nice to have" enterprise features, but critical tools that massively speed up iterative development, even for a solo developer.
