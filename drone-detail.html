Drone Assembly Simulator

A comprehensive PC/VR simulation for drone assembly demonstrating production-ready development cycles. Features a Unity VR client connected to a custom PHP REST API, with automated CI pipelines and cloud infrastructure managed via Azure and Terraform.

Backend PHP / REST API
Database Azure SQL

Unity VR Azure Terraform CI Pipeline Secret Management

Overview

Drone Assembly Simulator is not just a local VR experience; it's a fully integrated full-stack application. While the player interacts with drone components in virtual reality, the project serves as a showcase of a complete production pipeline.

The goal was to move beyond simple Unity gameplay and implement a robust architecture that handles cloud data, automated testing, and Infrastructure as Code (IaC).

Architecture & Stack

  • VR Client (Unity/C#): Clean architecture utilizing custom Editor Tools and comprehensive Unit Tests to ensure logic stability.
  • Backend Service (PHP): A custom REST API acting as a bridge between the VR client and the database.
  • Cloud Database (Azure SQL): Secure and scalable data storage hosted on Microsoft Azure.
  • Infrastructure (Terraform): The Azure environment is defined and deployed through code (Infrastructure as Code).
  • Continuous Integration (CI): Automated workflows utilizing a headless Unity client to execute Unit Tests. Includes secure secret injection, dynamically generating credential scripts only during the pipeline run to keep the repository strictly secure.

  run-tests:

3. Async API Client (UniTask)


namespace DroneAssembly.DataBase
{
    public class LeaderboardAPI : INetworkService
    {
        private string _saveScoreURL => Secrets.Secret.SaveScoreURL;

        public async UniTask<bool> SendPlayerDataAsync(string playerName, float time)
        {
            string jsonPayload = PreparePostData(playerName, time);
            
            using var cts = new CancellationTokenSource(TimeSpan.FromSeconds(60));
            using UnityWebRequest request = new UnityWebRequest(_saveScoreURL, "POST");
            
            byte[] bodyRaw = Encoding.UTF8.GetBytes(jsonPayload);
            request.uploadHandler = new UploadHandlerRaw(bodyRaw);
            request.SetRequestHeader("Content-Type", "application/json");

            try
            {
                await request.SendWebRequest().ToUniTask(cancellationToken: cts.Token);
                return request.responseCode == 200 || request.responseCode == 201;
            }
            catch (OperationCanceledException)
            {
                Debug.LogError("Time Limit Reached (Timeout)");
                return false;
            }

        }

Challenges & Learning

The most significant technical hurdle was bridging pure game development with DevOps security practices. Setting up a headless mock Unity client within the CI pipeline to reliably run tests was complex, but the real challenge was implementing a secure Secret Management system. Ensuring that API keys and Azure credentials were dynamically injected into the pipeline without ever being exposed in the version control required a deep dive into secure CI workflows.

This project fundamentally changed how I view software architecture. I learned that automated testing and strict infrastructure security (like Terraform and Secret Injection) are critical engineering practices that stabilize development, even for a solo developer.
